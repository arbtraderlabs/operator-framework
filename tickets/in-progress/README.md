# in-progress/

[`skills/execute-ticket.md`](../../skills/execute-ticket.md).

[`skills/report.md`](../../skills/report.md)), move the ticket to
[`../review/`](../review/). If verification later fails, tickets return
here for rework. See [`docs/ticket-system.md`](../../docs/ticket-system.md)
for the full lifecycle.
