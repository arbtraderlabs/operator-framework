# backlog/

Tickets that have been planned (via
[`skills/plan-tickets/skill.md`](../../skills/plan-tickets/skill.md)) but not yet
started. Move a ticket file here first, using
[`templates/ticket.md`](../../templates/ticket.md).

When work begins, move the file to [`../in-progress/`](../in-progress/).
See [`docs/TICKET_SYSTEM.md`](../../docs/TICKET_SYSTEM.md) for the full
lifecycle.
