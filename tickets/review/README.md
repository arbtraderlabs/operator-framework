# review/

Tickets whose execution is complete and are awaiting or undergoing
independent verification via [`skills/verify/skill.md`](../../skills/verify/skill.md).

On a pass, move the ticket to [`../done/`](../done/). On a fail, move it
back to [`../in-progress/`](../in-progress/) with the verification report's
findings addressed. See
[`docs/TICKET_SYSTEM.md`](../../docs/TICKET_SYSTEM.md) for the full
lifecycle.
